# Shortcuts

All of them use <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Shift</kbd> plus a key, so they do not clash with your apps. Change them in the main window, under **Shortcuts and gestures → Change shortcuts…**: click a shortcut, press the new combination and **Save**.

| Key | Action |
| --- | --- |
| <kbd>Backspace</kbd> | **Emergency:** puts every window back where it was. It always has a shortcut. |
| <kbd>D</kbd> | Show or hide the deck. |
| <kbd>↑</kbd> | Bring the active window to the focus. |
| <kbd>←</kbd> | Back to the previous focus app. Again, and you are back. |
| <kbd>↓</kbd> | Send the focus app back to its panel. |
| <kbd>F</kbd> | Fullscreen for the focus app on the main monitor, or back. |
| <kbd>V</kbd> | Next main screen layout. |
| <kbd>P</kbd> | Keep the screen on (on or off). |
| <kbd>1</kbd>…<kbd>9</kbd> | Apply a saved scene (from the main window). |

## Windows gestures

With the default settings, choosing a window that is in a panel with **Alt+Tab**, **Task view** (Win+Tab) or the **taskbar** brings it to the focus. Clicking a window does not. Change this in the main window, under **Shortcuts and gestures**.

Dragging a window onto the focus or onto another panel moves it there. Dragging it elsewhere and letting go puts it back in its place.
